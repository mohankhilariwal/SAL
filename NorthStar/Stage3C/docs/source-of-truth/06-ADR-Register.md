# 06 — ADR Register

`ADR-001`–`ADR-023` remain accepted and are not superseded.

| ID | Decision | Status |
|---|---|---|
| `ADR-024` | Use application-owned independent runtime budgets and a monotonic ledger; prompt/provider quotas are insufficient. | Accepted |
| `ADR-025` | Use typed failure recovery combining error class and side-effect impact; allow bounded read fallback and reconcile ambiguous writes before continuation. | Accepted |
| `ADR-026` | Add atomic checksummed local checkpoint/resume as a bounded pre-graph capability; do not claim distributed durable execution or audit. | Accepted |

Full ADRs are under `docs/adr/`.
