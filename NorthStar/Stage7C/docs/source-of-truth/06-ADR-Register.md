# 06 — ADR Register: Stage 7C Overlay

`ADR-001`–`066` remain accepted and are not superseded.

| ADR | Decision |
|---|---|
| `ADR-067` | Managed inference is the default deployment class; self-hosted serving is a governed benchmark lane. |
| `ADR-068` | Optimize context/output/streaming and exact prefix reuse before infrastructure complexity; prohibit semantic regulatory-answer caching. |
| `ADR-069` | Runtime owns batching/KV scheduling; quantization and parallelism remain concrete benchmark choices. |
| `ADR-070` | Speculative decoding is disabled by default and promoted only per profile after parity, acceptance, decode, E2E and memory gates. |
| `ADR-071` | Use a standard-library planner, analytical proxy and toy lossless speculation lab until endpoint evidence exists. |

Full records are under `docs/adr/`.
