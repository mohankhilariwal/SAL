# Stage 4A Technical Sources

Verified 2026-07-31. Primary sources only.

1. Python 3.13 documentation — `typing`, `dataclasses`, `enum`, `copy` and standard-library serialization primitives.
2. LangGraph official Graph API documentation — nodes, normal edges and conditional edges; used as a representative graph-framework option, not as the selected runtime.
3. AWS Step Functions Developer Guide — state machines, states, transitions, Choice states and terminal states; used as a managed-workflow comparison.
4. Temporal official documentation — durable execution and resumption; used to distinguish Stage 4A local checkpoints from a production durable workflow service.
5. JSON Schema Draft 2020-12 official specification — schema vocabulary baseline for the graph/state contracts.

No vendor capability is represented as a NorthStar standard. Version-sensitive claims should be reverified before production selection.
