# ADR Register — 0.9.0

`ADR-001`–`ADR-029` remain accepted.

- `ADR-030`: place human approval after deterministic completion of the unapproved evidence package.
- `ADR-031`: use a persisted external-event wait with explicit expiry instead of blocking a process or polling.
- `ADR-032`: use a transactional SQLite adapter for the local stage while preserving a migration seam to a production durable workflow engine.
