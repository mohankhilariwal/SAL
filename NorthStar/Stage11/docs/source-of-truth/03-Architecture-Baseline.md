## Final target state

The target state is a human-accountable, single-agent, graph-controlled regulatory-assessment system with externalized authority, gateway-only tools, access-aware evidence, deterministic guardrails, evaluation, audit, reliability, FinOps and readiness evidence. The production route is not part of the implemented baseline and remains disabled.
