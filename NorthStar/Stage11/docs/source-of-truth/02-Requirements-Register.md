## Stage 11 requirements

`S11-FR-001`–`018` are defined in the Stage 11 chapter Section 4. They require final reconciliation, evidence indexing, conjunctive blockers, non-authorizing readiness, topology comparison, diagrams, threat/evaluation/RACI/runbook consolidation, local manifest, assignment, bibliography, inherited-invariant preservation, explicit Stage 8D/9D status, stage closure and runnable validation.

## Final acceptance

- Architecture package can be built and reconciled locally.
- Final assessment is `denied` and route disabled.
- Exactly one active agent remains.
- No new tool or top-level component is introduced.
- All new outputs have `authority_effect: none`.
- Stage 11 tests and gates pass with recorded historical and production-evidence exceptions.
