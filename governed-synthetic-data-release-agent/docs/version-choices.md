# Version choices — 2026-08-04

The repository supports CPython 3.12 and 3.13. Python 3.12 is the conservative Mac recommendation; Python 3.13 was used for the core execution recorded in `artifacts/verification-report.md`.

## Selected direct dependencies

The declared ranges in `pyproject.toml` intentionally allow compatible patch/minor updates while preventing unreviewed major-version changes. `requirements.lock` records the direct versions selected during this build and is regenerated by `make setup` using `pip freeze` on the target Mac.

Key selections include:

- Pydantic v2 and FastAPI for typed API contracts.
- SQLAlchemy 2 and Alembic for SQLite persistence and migration.
- pandas, NumPy, SciPy and scikit-learn for deterministic data and metric computation.
- SDV Gaussian Copula as the full-stack default with a deterministic offline fallback.
- SDMetrics and Presidio as optional full-stack integrations; core governance tests do not depend on them.
- Streamlit for the five-screen demonstration UI.
- Ruff, Mypy, Pytest and pytest-cov for developer verification.

## Compatibility posture

- No Docker is required for local execution.
- Ollama and OPA are optional adapters; absence cannot break the default flow.
- The domain and application layers do not import cloud SDKs.
- Exact transitive versions should be reviewed and vulnerability-scanned before a production build.
- Cloud-service names in `docs/cloud-portability.md` are migration examples and must be revalidated for region, lifecycle status, data residency and pricing at deployment time.
